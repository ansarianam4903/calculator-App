# Calculator App
## About the Project
Calculator App is a simple calculator developed using Python.
It performs basic mathematical operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Remainder
- Power calculation
- Error handling
- User-friendly menu

## Technologies Used
- Python 3
- Functions
- Conditional Statements
- While Loop
- User Input
- Exception Handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Run this command:

```bash
python calculator.py
```
